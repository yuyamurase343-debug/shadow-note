# シャドーノート

シャドーイングを録音すると、言えていない語を赤字で示し、タップするとカタカナで発音のコツを表示するWebアプリです。データはiPhone内（IndexedDB）にだけ保存されます。

## 公開のしかた（GitHub Pages・無料）

1. GitHub で新しいリポジトリを作る（例：`shadow-note`）。
2. 「Add file → Upload files」で、このフォルダの中身をすべてアップロードする（`index.html` がリポジトリ直下に来るように）。
3. 「Settings → Pages」で Source を `main` ブランチ / `(root)` にして保存。
4. 1〜2分後に `https://<ユーザー名>.github.io/shadow-note/` が開けるようになる。

## iPhone のホーム画面に追加

1. 上のURLを **Safari** で開く。
2. 共有ボタン →「ホーム画面に追加」。
3. ホーム画面のアイコンから起動し、最初の録音でマイクを許可する。

## 使い方のメモ

- 初回の文字起こしでモデル（約80MB）をダウンロードします。Wi-Fiで「設定 → モデルを今ダウンロードしておく」を押しておくと安心です。以後はオフラインでも動きます。
- お手本を流しながら録音するときはイヤホンを使うと、お手本の音が録音に混ざりません。
- 赤字は「認識された文」とスクリプトのずれから判定しています。単語として通じたかは分かりますが、細かな発音の質（例：ハフトゥーと言ってもhave toと認識されれば赤字にならない）は判定できません。発音ガイドで全体の音の変化を確認しながら練習してください。

## ファイル

- `index.html` 画面とデザイン
- `app.js` 教材管理・再生・録音・結果表示
- `pron.js` カタカナ変換と音声変化ルール（連結・フラップ・脱落・同化・弱形・定型フレーズ）、照合
- `worker.js` 端末内 Whisper による文字起こし
- `cmudict.txt` CMU 発音辞書（約12.6万語）
- `sw.js` / `manifest.json` / `icon-*.png` ホーム画面アプリ化とオフライン対応
